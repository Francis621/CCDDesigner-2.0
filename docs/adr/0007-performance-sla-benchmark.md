# ADR-0007: 性能指标量化环境基准 (Performance SLA Benchmark Environment)

## 状态
已接受 (Accepted) - 上位强制冻结项

## 上下文
说明书第 8.2 节定义了多项严格 SLA（如常规并发 P95 <= 2s、万行 BOM 展开 P95 <= 3s、百万关系图遍历 P95 <= 5s）。在性能测试中，若测试环境不明确或混淆页面端到端与求解器耗时，测试结果将失去客观性。

## 决策
1. 性能 SLA 指标必须在标准基准硬件与拓扑下测量（独立应用容器、专用数据库与高速网络）。
2. 必须严格区分“业务事务响应时间”与“求解器/异步作业执行耗时”；异步求解（如 OpenModelica）通过 Job/Run 状态轮询解耦，不纳入同步 HTTP API 响应时长考核。
3. 超万行的大规模 BOM 展开与全量导出必须走异步任务队列，首屏仅加载可视视口数据（<= 200行）。

## 影响
- **正面**：SLA 考核科学量化，避免架构团队因外部长耗时计算背负不切实际的同步 HTTP 响应指标。
- **负面**：前端必须针对大数据量表格与拓扑图设计虚拟滚动与流式加载。
