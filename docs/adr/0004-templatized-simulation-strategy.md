# ADR-0004: 仿真模板化填报策略 (Templatized Simulation Strategy)

## 状态
已接受 (Accepted) - 上位强制冻结项

## 上下文
机床系统级多物理场仿真极其复杂。如果试图在第一期实现基于模型拓扑自由自动生成 Modelica 方程，研发周期不可控且收敛难度极大。

## 决策
1. P0/P1 首期仅支持**参数填报式模板仿真**。
2. 系统预先在 M09 仿真模型库中归档经过试验校准的标准物理组件模板（如轴系伺服阶跃响应、主轴温升热力学模板）。
3. M08 负责将系统工程参数（M07）按映射矩阵注入既有模板的输入参数槽，直接交由 M10 求解器解算，不在线动态生成多物理方程拓扑。

## 影响
- **正面**：聚焦高频刚需场景（轴系跟随误差、主轴转速温升），保障工程落地可行性与求解收敛率。
- **负面**：暂不支持任意自由拓扑仿真，复杂新机型需预先由仿真专家沉淀分析用例模板。
