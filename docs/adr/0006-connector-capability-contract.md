# ADR-0006: 外部工具连接器准入契约策略 (Connector Capability Contract)

## 状态
已接受 (Accepted) - 上位强制冻结项

## 上下文
平台需接入多种外部异构系统（CAD 客户端插件、MES、ERP、IoT 平台等）。各外部系统的并发承载能力、超时时间与接口规范差异巨大，若无准入控制易引发核心服务级联崩溃。

## 决策
1. 外部连接器接入必须按能力清单（支持的操作集合、单批次最大载荷、超时阈值、重试策略）完成受控准入认证。
2. 严禁外部系统绕过 API 网关直接读写核心底表；所有交互均通过强类型 OpenAPI 接口与消息队列。
3. 针对异步制造回传（MES），严格执行带有业务流水号的逐项 Receipt 对账与 `sourceSystem + externalEventId` 强去重。

## 影响
- **正面**：保护 PLM 核心不受外部异常冲击，保证跨系统集成的稳健性。
- **负面**：外部系统对接需提供标准认证驱动或适配层。
