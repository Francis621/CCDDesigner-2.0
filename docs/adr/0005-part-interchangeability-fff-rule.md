# ADR-0005: 零部件互换性准则 (Part Interchangeability FFF Rule)

## 状态
已接受 (Accepted) - 上位强制冻结项

## 上下文
在数控机床研发与生产中，若零件发生形状（Form）、配合（Fit）或功能（Function）改变，盲目使用升版（如 Rev A -> Rev B）会导致在制订单、库存件及售后换件严重混乱。

## 决策
1. 严格推行“**FFF 改变必须新建物料编号**”的军工/高端装备工程准则。
2. 仅当新零件完全向前向后双向兼容（双向可互换）时，才允许在原物料编号下发布新工程修订版本（Revision）。
3. 若互换性被破坏，必须分配新的 `partMasterId`，并通过 M16 替代料关系或 M22 工程变更管理生效。

## 影响
- **正面**：物理实物库存与售后维护的绝对安全性，杜绝现场因版本差异导致装配装不进或功能不匹配。
- **负面**：设计变更时需严格判定互换性，增加设计团队的物料准入审核步骤。
