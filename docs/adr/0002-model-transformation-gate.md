# ADR-0002: 模型转换准入控制策略 (Model Transformation Gate)

## 状态
已接受 (Accepted) - 上位强制冻结项

## 上下文
SysML v2 规范庞大，外部编辑环境（如 SysON、文本 OpenSysML）可能引入平台当前语义子集尚未支持的高级语法或降级构造。如果发布时系统采取宽容策略进行静默丢弃或隐式降级，将导致发布态模型失真且难以察觉（违反 AT-02 验收用例）。

## 决策
1. 建立显式且严格的兼容性准入配置（`CompatibilityProfile`）。
2. 在 M06 发布前置校验阶段，针对不支持的 SysML v2 语法元素或降级构造实施**硬阻断（Hard Failure）**。
3. 校验引擎必须输出结构化诊断报告（包含违规元素行号、元素标识与原因），严禁静默截断后强行发布。

## 影响
- **正面**：确保进入 Flexo 生产模型库的每一个 Commit 都是 100% 语法精确且语义完整的。
- **负面**：对建模工程师的建模规范性要求严格，需在 M04 建模工作区提供前置诊断辅助。
