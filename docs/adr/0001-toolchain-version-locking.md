# ADR-0001: 工具链版本绑定策略 (Toolchain Version Locking)

## 状态
已接受 (Accepted) - 上位强制冻结项

## 上下文
系统高度依赖外部专业工具（SysON、OpenSysML、Flexo、OpenModelica 及 CAD 插件）以及行业标准建模库。若外部环境或容器使用动态版本（如 `:latest`），将导致模型语法解析差异、仿真结果不确定性以及历史基线不可重现（违反 AT-06、AT-14 验收用例）。

## 决策
1. 生产与测试环境严禁使用 `latest` 标签镜像或动态拉取策略。
2. 必须锁定指定工具的精确语义化版本号（SemVer）与构建镜像的 SHA-256 摘要（例如 `openmodelica:1.22.0-omc@sha256:...`）。
3. 建模标准库（数控机床行业模型库）必须随平台工程发布一同冻结版本，历史发布的模型永久绑定其依赖库的快照版本。

## 影响
- **正面**：彻底消除外部工具漂移带来的仿真与解析风险，保障模型与证据的 100% 可审计、可重现。
- **负面**：外部工具升级需走受控评估流程，通过回归测试后方可签发升级单。
