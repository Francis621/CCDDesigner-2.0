# ADR-0003: Flexo 候选模型暂存与分支隔离策略 (Flexo Staging Isolation Strategy)

## 状态
已接受 (Accepted) - 上位强制冻结项

## 上下文
在两阶段受控模型发布流程中，候选快照需预先写入 Flexo 进行校验并生成不可变 CommitID。未经过 M24 正式审批通过前，若该候选 Commit 被普通用户在生产查询接口查到，将造成未受控设计外溢与质量事故。

## 决策
1. Flexo RDF 存储必须支持独立命名空间（Namespace）或暂存隔离分支（Staging Branch）。
2. 审批流未通过前，写入的 Commit 处于 STAGING 隔离状态，对生产检索、BOM 关联和数字主线遍历完全不可见。
3. 仅当 M24 返回正式批准凭证并经 M06 本地事务原子激活后，该 Commit 状态方可转为正式发布，对全系统开放只读消费。

## 影响
- **正面**：实现跨系统发布候选物理隔离，支持审批驳回后的干净回收。
- **负面**：Flexo 适配器需维护隔离命名空间与生产命名空间的分支流转逻辑。
